# Skill — decidir_escala

## Entrada
Campanha, orçamento, gasto, CPA, ROAS, margem, estabilidade, capacidade e objetivo.

## Decisões
MANTER / AUMENTAR ORÇAMENTO / LATERALIZAR / REDUZIR / AGUARDAR / DESATIVAR

## Regras
- Gasta 100% + ROAS forte → testar aumento
- Não gasta 100% + ROAS forte → diagnosticar/lateralizar
- ROAS alto + pouco volume → testar estrutura mais aberta
- Volume alto + ROAS baixo → aumentar controle
- Toda decisão deve ter condição de parada
