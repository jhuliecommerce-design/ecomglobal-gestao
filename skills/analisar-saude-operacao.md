# Skill — analisar_saude_operacao

## Áreas
Loja, mídia, criativos, fornecedor, suporte, financeiro e equipe.

## Processo
1. Ler KPIs por área.
2. Classificar VERDE/AMARELO/VERMELHO.
3. Encontrar dependências entre áreas.
4. Criar plano de ação.

## Saída
Painel de saúde + 3 maiores riscos + 3 prioridades.
