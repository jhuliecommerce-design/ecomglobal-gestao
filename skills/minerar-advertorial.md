# Skill — minerar_advertorial

## Objetivo
Extrair arquitetura persuasiva de um advertorial concorrente sem copiar texto.

## Captura
Headline, lead, dor, mecanismo, promessa, provas, objeções, CTA, oferta e ordem dos blocos.

## Saída
Mapa estrutural + elementos reaproveitáveis + elementos que precisam ser substituídos.
