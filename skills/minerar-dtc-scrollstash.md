# Skill — minerar_dtc_scrollstash

## Objetivo
Executar pesquisa estruturada no ScrollStash e devolver inteligência utilizável para DTC.

## MCP
`https://mcp.scrollstash.com/mcp`

## Sequência recomendada

### Descoberta
search_brands → rank_brands

### Marca
get_brand_profile → analyze_brand

### Funil
get_brand_landing_pages → get_funnel_strategy → get_domain_landers

### Criativos
search_ads → research_category_angles → get_brand_breakdown

### Comparação
compare_brands

## Princípio
Primeiro descobrir padrões, depois aprofundar marcas específicas.

## O que extrair
- produto
- promessa
- dor
- ângulo
- formato
- CTA
- lander
- quiz
- advertorial/listicle
- frequência observada
- recência
- longevidade observada

## O que NÃO inferir
Não inferir:
- spend
- CPA
- ROAS
- faturamento
- conversão
- market share
- "criativo vencedor"

## Saída
Tabela de marcas + mapa de ângulos + mapa de funil + shortlist de hipóteses para modelar.
